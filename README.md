# Лендинг «Решение» · Студия инструментов мышления

Одностраничный сайт для продажи PDF-блокнота «Решение · 01 Профессия» —
протокола одного решения в 6 стадий.

Дизайн перенесён с макетов блокнота: хвоя #2D4A3E + бумага «Кость»,
IBM Plex Sans / IBM Plex Mono, керн-шкала стадий как навигация.
Все цвета и шрифты собраны в блоке `:root` в начале `styles.css`.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Вся структура страницы и тексты. Правки текстов — здесь. |
| `styles.css` | Все стили. Цвета и шрифты меняются в самом верху файла (блок `:root`). |
| `script.js` | Небольшой скрипт: тень у шапки + напоминание, если кнопка оплаты ещё не подключена. |

## Где заменить ссылки перед запуском

1. **Кнопка оплаты** — в `index.html` найдите комментарий `КНОПКА ОПЛАТЫ` (блок с id `price`) и замените `href="#"` на вашу платёжную ссылку (Stripe / ЮKassa / Gumroad).
2. **Почта** — в футере замените `hello@example.com` на свою.
3. **Соцсети** — в футере замените `#` на ссылки на ваши профили Telegram / Instagram / VK.
4. **Цена** — цифры в блоке `price-amount` в `index.html`.

## Как опубликовать (кратко)

Самый простой путь — Netlify Drop:

1. Зайдите на https://app.netlify.com/drop
2. Перетащите папку с этими тремя файлами в окно браузера.
3. Через ~10 секунд сайт получит адрес вида `https://имя.netlify.app`.

Подробная пошаговая инструкция (домен, оплата, автоотправка PDF) — в переписке с Claude или у меня в заметках.
