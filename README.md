# «Решение» / «Decision» — два независимых сайта

Два отдельных сайта для двух разных аудиторий. Каждая папка самодостаточна:
её можно целиком загрузить на свой хостинг, со своим доменом и своей оплатой.
Между собой сайты никак не связаны и не ссылаются друг на друга.

```
ru/     Русский сайт — блокнот «Решение · Модуль 01»
en/     Английский сайт — DECISION, Thinking Tools Studio
```

## Что внутри каждой папки

| Файл | Что это |
|---|---|
| `index.html` | Вся страница и тексты. Правки текстов — здесь. |
| `styles.css` | Все стили. Цвета и шрифты меняются в блоке `:root` в начале файла. |
| `script.js` | Небольшой скрипт: линия у шапки, выбор цвета обложки, заглушка кнопки оплаты. |
| `fonts.css` + `fonts/` | Шрифты IBM Plex, подключены локально. **Обязательно загружать вместе с сайтом** — без них слетит вся типографика. |

В папке `ru/` дополнительно лежит приложение — цифровая версия блокнота:
`app.html`, `app.css`, `app.js`. Открывается по адресу `ваш-домен.ru/app.html`.

Комментарии в коде: в `ru/` — на русском, в `en/` — на английском.

## Что заменить перед запуском

В каждой папке отдельно:

1. **Кнопка оплаты** — в `index.html` найдите комментарий про кнопку оплаты
   и замените `href="#"` на платёжную ссылку.
   Для `ru/` — ЮKassa или Т-Касса, для `en/` — Stripe.
2. **Почта** в футере вместо `hello@example.com`.
3. **Соцсети** в футере вместо `#`.
4. **Цена** — в блоке `price-amount`.
5. **Фотографии обложек** — сейчас обложки нарисованы кодом. Когда появятся
   фото, замените блоки `.cover` на `<img>` (место помечено комментарием).

## Публикация

Каждая папка загружается на хостинг как отдельный сайт — содержимое папки
кладётся в корень (обычно `public_html`), не саму папку, а то, что внутри.

- `ru/` — российский хостинг (Timeweb, Beget) + домен `.ru`;
  открывается в России без VPN.
- `en/` — любой хостинг (Netlify, Vercel, Cloudflare Pages) + домен `.com`.

Шрифты локальные, внешних запросов сайты не делают вообще.
