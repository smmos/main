# vizhu.notes — сайты серии блокнотов «Решение»

Два независимых сайта для двух рынков. Каждая папка самодостаточна:
её содержимое загружается на свой хостинг, со своим доменом.

```
ru/     Российский сайт — vizhu.notes, каталог серии, предзаказ
en/     Английский сайт — DECISION (пока со старым названием студии)
```

Российский сайт устроен как витрина марки: слайдер с примерами решений
(листается сам), бегущая строка, четыре факта, каталог и общая форма
предзаказа. У каждого блокнота своя кнопка «Предзаказ» — она отмечает
этот блокнот в форме внизу страницы.

### Как добавить ещё один блокнот в серию

В `ru/index.html` нужно поправить три места — все помечены комментариями:

1. Скопировать блок `<article class="slide">` в слайдере и блок
   `<article class="product">` в каталоге, поменяв в них краску `--c`,
   название, описание и `data-notebook` у кнопки.
2. Добавить одну `<button>` в блок точек `<div class="dots">`.
3. Добавить `<label class="pick">` в форму предзаказа — с тем же
   значением `value`, что стоит в `data-notebook` у кнопки.

## Что внутри каждой папки

| Файл | Что это |
|---|---|
| `index.html` | Вся страница и тексты. Правки текстов — здесь. |
| `styles.css` | Все стили. Цвета и шрифты меняются в блоке `:root` в начале файла. |
| `script.js` | Скрипт: линия у шапки, прокрутка к форме, отправка почты. |
| `fonts.css` + `fonts/` | Шрифты IBM Plex, подключены локально. **Обязательно загружать вместе с сайтом.** |

В папке `ru/` дополнительно лежит приложение — цифровая версия блокнота:
`app.html`, `app.css`, `app.js`. Открывается по адресу `ваш-домен.ru/app.html`.
Оно использует из `styles.css` переменные и классы `.container`, `.site-header`,
`.logo`, `.btn`, `.eyebrow`, `.kern*` — их нельзя удалять.

## Обязательный шаг перед публикацией русского сайта

Форма предзаказа сама по себе **не хранит почту** — сайт состоит только из файлов.
Нужен бесплатный сервис форм:

1. Заведите форму на любом сервисе (Formspree, Getform, Web3Forms, Яндекс Формы).
2. Скопируйте адрес, на который форма отправляет данные.
3. Откройте `ru/script.js` и вставьте его в первую строку настройки:
   `const FORM_ENDPOINT = 'https://formspree.io/f/вашкод';`

Пока строка пустая, форма честно говорит посетителю, что приём заявок ещё
не открыт, и не делает вид, что письмо ушло. Адреса при этом не теряются молча.

## Что ещё заменить

1. **Почта** в футере вместо `hello@example.com`.
2. **Соцсети** в футере вместо `#`.
3. **Фотографии обложек** — сейчас обложки нарисованы кодом. Когда появятся
   фото, замените блоки `.cover` на `<img>` (место помечено комментарием).

## Публикация

Загружается **содержимое** папки, а не сама папка: `index.html` должен
оказаться в корне сайта.

- `ru/` — Netlify или российский хостинг (Timeweb, Beget) + домен `.ru`
- `en/` — любой хостинг + домен `.com`

Шрифты локальные, внешних запросов сайты не делают вообще.
